Method: implied value follows from the snapshot's own figures only — TVL, seven-day TVL change and days listed with no token. A protocol is shown as pre-token when its DefiLlama record carries no market cap, CoinGecko id or symbol; that is what the record says, never proof it has no token. The board never predicts whether or when a token is issued, and an implied value is this entry's own claim, never make.fun's.
